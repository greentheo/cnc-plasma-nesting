# G-code Visualizer

A simple browser-based tool to visualize and validate G-code files for CNC/plasma cutting operations.

## Features

- Drag and drop G-code files (.nc, .gcode, .txt) for quick visualization
- Color-coded visualization:
  - **Blue lines**: Rapid moves (G0)
  - **Green lines**: Linear cuts (G1)
  - **Red lines**: Arc moves (G2/G3)
  - **Orange dots**: Pierce points
- Interactive controls:
  - Pan by dragging the visualization
  - Zoom with mouse wheel or slider
  - Reset view and fit to screen options
- Visual grid with dynamic scaling
- File statistics including:
  - Dimensions
  - Number of lines
  - Number of moves (rapid, cutting)
  - Number of pierce points
  - Travel distances (rapid, cutting, total)

## How to Use

1. Open `index.html` in your web browser
2. Load a G-code file using one of these methods:
   - Click the file input and select your G-code file
   - Drag and drop a G-code file onto the canvas area

## Interpreting the Visualization

- **Blue lines** represent rapid moves (G0) where the torch is traveling but not cutting
- **Green lines** represent cutting moves (G1) where the torch is actively cutting
- **Red lines** represent arc moves (G2/G3)
- **Orange dots** indicate pierce points where the torch turns on (M3 commands)
- A grid and coordinate system helps you verify dimensions and position

## Detecting Common G-code Problems

This visualizer can help identify several common issues in G-code:

1. **Excessive travel**: Look for long blue lines crisscrossing the workspace, indicating inefficient travel paths
2. **Missing cuts**: Gaps in green lines may indicate missing cut segments
3. **Duplicate cuts**: Overlapping green lines may indicate redundant cutting paths
4. **Out of bounds**: Parts extending beyond expected dimensions
5. **Incorrect scale**: Parts appearing much larger or smaller than expected
6. **Misplaced pierce points**: Pierce points that don't align with the start of cut paths

## For ShapPack Users

When visualizing G-code generated by ShapPack:

1. Check that torch travel paths (blue lines) efficiently move between parts
2. Verify that pierce points are properly placed at the start of each part
3. Confirm that the torch-off travel paths don't cross through already cut parts
4. Look for any unexpected patterns in the travel path optimization
